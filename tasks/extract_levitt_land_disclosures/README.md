# Levitt land disclosures

This task reviews the Levitt Corporation / Woodbridge Holdings 10-Ks for fiscal 2004-2007. The 2004-2006 filings report a homebuilding pipeline, but the current-development rows explicitly include an unquantified number of optioned lots. The task therefore retains pipeline scale and operating fields without constructing an owned-versus-optioned share.

The 2007 filing reports that Levitt and Sons ceased development in September, filed Chapter 11 in November, and was deconsolidated from the public parent. That row is retained as a documented firm exit rather than a missing continuing-firm disclosure.

Run `make` from `tasks/extract_levitt_land_disclosures/code/`.
