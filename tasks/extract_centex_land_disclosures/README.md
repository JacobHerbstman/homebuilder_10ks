# Centex Land Disclosures

This task extracts Centex (`CTX`) fiscal 2004-2009 owned and controlled lot counts from the firm-specific land-position tables in its 10-K filings.

Centex uses a March 31 fiscal year and was acquired by Pulte in August 2009. The rows remain Centex standalone fiscal-year observations and should be interpreted with the non-December fiscal-year warning retained in the universe file.

Outputs:
- `ctx_2004_2009_land_panel.csv`
- `ctx_2004_2009_extraction_audit.csv`
- `ctx_2004_2009_source_notes.csv`
