# Expanded Builder Sample Audit

This task reconciles every Builder Magazine name ever marked public against the expanded SEC builder universe, records explicit scope exclusions, and documents why the remaining land-share gaps cannot be converted into comparable owned-versus-nonowned physical shares.

Run from `tasks/audit_expanded_builder_sample/code/`:

```sh
make
```

The operating-readiness output distinguishes Builder survey closings, the audited six-firm SEC pilot, generic parser coverage, and the expanded firm-specific land panel. A metric being present in a generic candidate table is not treated as sufficient for cross-firm descriptive analysis.
